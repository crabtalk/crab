# Web

Services for reading, inspecting and measuring websites.

- [SEO](seo/README.md): technical page checks, AI crawler access and site audits, published as `crabtalk/seo`.
- [Analytics](analytics/README.md): website funnels and Stripe revenue attribution, configured as `crabtalk/analytics`.

Publish SEO with `crab push services/web/seo` from a Cloud context that can publish to `crabtalk`.
