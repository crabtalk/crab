# Utilities

Services that perform a task using one or more capabilities, with their own behavior and state.

- [SEO check](seo/README.md): basic page metadata and indexing findings.
- [Webpage → Markdown](webpage/README.md): read public HTML pages without an upstream API key.
- [Release watch](release-watch/README.md): retained release and vulnerability observations.

Call an accessible running deployment or deploy a published template as a private copy. Availability and required setup are documented by each service; the catalog does not determine deployment visibility.

See [Services](../README.md) for source builds and Rust library reuse.
